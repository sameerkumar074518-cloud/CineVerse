                                          🎬 CineVerse

CineVerse is a professional-grade, full-stack cinematic streaming platform designed to provide a premium user experience. Built with a modern tech stack, it features a sleek Netflix-style UI, real-time database integration, and a cinematic video background login.

## 🚀 Features

- **Cinematic UI:** A high-definition, responsive interface with smooth scroll animations.
- **Video Background Login:** A custom login experience featuring a muted, looping video backdrop.
- **Real-time Database:** Integration with Firebase/MongoDB for user authentication and "My List" management.
- **Search & Filter:** Instant search functionality by title or genre.
- **Custom Video Player:** Integrated playback with support for multiple formats and metadata.
- **My List:** Personalized collection for users to save their favorite titles.
- **Dynamic Help Centre:** Custom on-screen modal for user guidance and technical support.

## 🛠️ Tech Stack

**Frontend:**
- React.js
- JavaScript (ES6+)
- CSS3 (Custom Animations & Layouts)

**Backend & Database:**
- Node.js & Express
- Firebase (Auth & Storage)
- Render (Deployment)
